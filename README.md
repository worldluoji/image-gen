# IMAGE GEN

核心功能：调用大模型生成图片，支持文生图、图生图、图生视频。

一期仅支持 MiniMax H3。

## 功能

- **文生图**：输入文字描述，选择模型（`image-01` / `image-01-live`）、宽高比、生成数量（1-9）与画面风格，调用 MiniMax `image_generation` 接口生成图片。API Key 仅存于服务端，浏览器不直接接触密钥。
- **风格选择**：预设 16 种常用画风——电影 / 写实 / 日漫 / 国风动漫 / 3D 卡通 / 水彩 / 油画 / 素描 / 中国水墨 / 像素艺术 / 赛博朋克 / 复古胶片 / 扁平插画 / 儿童绘本 / 浮世绘 / 概念艺术，以带示例图的卡片网格展示（样图预生成入库于 `public/styles/`），点选即切换；也可选「无」或「自定义」输入风格描述（≤100 字符）。风格会拼接进 prompt 发送给模型（上游 API 的 `style` 参数仅支持 4 种固定画风且只对 `image-01-live` 生效，故未采用）。
- **图生图**：在同一表单上传参考图（JPG / PNG，< 10MB，建议人物主体清晰），即以 `subject_reference` 调用同一接口进行人物主体参考生成；不传图则为文生图。
- **描述辅助**：输入框下方提供 6 个示例模板（人像 / 风景 / 城市夜景 / 产品海报 / 绘本场景 / 桌面壁纸）与「最近」历史描述快捷填入，点击即替换输入框内容。
- **AI 润色**：输入框右下方「AI 润色」按钮，调用 MiniMax 文本模型（`MiniMax-Text-01`）把大白话描述扩写为更具体的绘图提示词（保留原意与主体，补充细节、构图、光线），结果直接替换输入框内容。
- **图片持久化与下载**：生成成功后服务端自动将图片落盘到 `public/generated/`（上游 URL 仅 24 小时有效，落盘后永久可用），每张结果图可直接下载。
- **图片放大预览**：点击结果图或历史缩略图打开灯箱，支持 ←/→ 键或按钮在多图间切换、ESC 或点击背景关闭，灯箱内可直接「作为参考图」与「下载」。
- **生成历史**：每批生成记录（描述、参数、图片）持久化到 `data/history.json`，页面底部展示历史；可「载入参数」回填表单，点击缩略图放大预览，可「删除」单批（二次确认，同步清理其落盘图片/视频），可「收藏置顶」（星标切换，收藏条目恒排最前且不参与截断，最多收藏 49 批）；超出 50 批自动截断最旧的非收藏批次，被淘汰批次的落盘文件一并删除，磁盘不再无限累积。
- **用量限额**：页脚展示今日用量（图片 / 视频 / 润色）。服务端每日限额：图片 200 张、视频 30 个，并发生成请求上限 2——超限返回 429 友好提示，属轻量防误用（无鉴权，不防刻意刷）。
- **快速再创作**：结果区支持「作为参考图」（服务端自动将本地图转为 Base64 传给上游）与「再创作一批」（一键复用上一批全部参数重新生成）。
- **图生视频**：结果图可一键「生成视频」——弹窗预填原图描述（可编辑），选择时长（6 / 10 秒）与分辨率（768P / 1080P，10 秒仅支持 768P），调用 MiniMax `video_generation` 接口（模型 `MiniMax-Hailuo-2.3`）创建任务；前端每 5 秒轮询状态，成功后视频自动落盘并可直接播放、下载（上游下载链接仅 1 小时有效）。进行中任务随历史记录持久化，刷新页面后自动恢复轮询，历史区显示「视频生成中…」。视频记录挂在对应历史图片上，重启后仍可在历史区回放。
- **过程反馈与重试**：生成中按所选数量与宽高比显示骨架占位；部分失败时明确提示成功/失败张数并提供「重试失败的 N 张」（复用同参数、数量取失败数）；视频生成失败或超时时在结果区提供「重试」，复用上次的弹窗参数。

## 快速开始

1. 环境要求：Node.js >= 22，pnpm
2. 安装依赖：`pnpm install`
3. 配置密钥：复制 `.env.example` 为 `.env.local`，填入 `MINIMAX_API_KEY`
4. 开发运行：`pnpm dev`，打开 http://localhost:3000

## 项目结构

- `app/page.tsx` — 文生图表单页面（风格卡片、结果卡片、历史区、骨架屏、视频轮询与刷新恢复）
- `app/video-dialog.tsx` — 图生视频弹窗（描述编辑、时长/分辨率选择）
- `app/lightbox.tsx` — 图片放大预览灯箱（多图切换、作为参考图、下载）
- `app/api/generate/route.ts` — 生成接口 Route Handler（参数校验、每日额度与并发检查、密钥读取、错误映射、图片落盘、写历史、记用量）
- `app/api/video/route.ts` — 图生视频接口 Route Handler（POST 创建任务并挂载 pendingVideo、GET 轮询状态并落盘写历史、成功后记用量）
- `app/api/polish/route.ts` — AI 润色接口 Route Handler（文本模型扩写描述、记用量）
- `app/api/history/route.ts` — 历史记录查询接口
- `app/api/history/[id]/route.ts` — 历史记录删除（DELETE，同步清理落盘文件）与收藏切换（PATCH）接口
- `app/api/usage/route.ts` — 今日用量查询接口（页脚展示）
- `lib/minimax.ts` — MiniMax 客户端（请求构造 / 响应解析 / 通用 fetch 封装 `requestMiniMax` / 风格样图路径）
- `lib/video.ts` — MiniMax 视频接口封装（创建 / 查询 / 检索下载链接、参数校验）
- `lib/polish.ts` — MiniMax 文本接口封装（润色请求构造 / 响应解析与清洗）
- `lib/storage.ts` — 图片/视频落盘与历史持久化（本地参考图转 Base64、进行中视频任务读写、收藏置顶、删除与截断文件清理）
- `lib/usage.ts` — 每日用量统计与限额（翻篇归零、超额判断）
- `lib/prompt-templates.ts` — 描述示例模板与最近描述提取
- `lib/minimax.test.ts`、`lib/video.test.ts`、`lib/storage.test.ts`、`lib/polish.test.ts`、`lib/usage.test.ts`、`lib/prompt-templates.test.ts` — 单元测试
- `scripts/gen-style-samples.mts` — 一次性脚本，预生成 `public/styles/` 风格样图（`node --env-file=.env.local scripts/gen-style-samples.mts`）

## 说明

- 上游返回的图片 URL 有效期为 24 小时；服务端会在生成成功后自动落盘到 `public/generated/`（已 gitignore），单张落盘失败时回退使用远端 URL。
- 生成超时时间为 120 秒。
- 「作为参考图」使用本系统生成的图片时，由服务端读取落盘文件转为 Base64 Data URL 传给上游（上游无法访问本地地址）。
- 图生视频的首帧同样走本地文件转 Base64 Data URL；上游视频下载链接仅 1 小时有效，服务端在任务成功后立即下载落盘到 `public/generated/`（与图片同目录，已 gitignore）。
- 视频任务由前端轮询：每 5 秒查询一次，最长等待 15 分钟，超时后提示重试。任务创建时 `taskId` 会挂到历史图片的 `pendingVideo` 字段，刷新页面后据此自动恢复轮询。
- 风格样图位于 `public/styles/`（提交入库，按 `STYLE_PRESETS` 索引命名），改动风格预设后需重跑 `scripts/gen-style-samples.mts` 重新生成。
- 多标签页同时对同一视频任务轮询时，可能重复下载落盘同一视频（历史读改写非原子），属个人工具可接受的边界，未加锁。
- 删除历史与「生成视频」都基于读改写，二者并发时理论上存在互相覆盖的窗口，同上未加锁；删除条目引用的文件名经严格正则校验，不会越界删除。
- AI 润色调用 MiniMax 文本接口（`/v1/chat/completions`，模型 `MiniMax-Text-01`），超时 30 秒；结果自动剥离代码围栏与引号，超 1500 字符截断。
- 每日用量与限额记录在 `data/usage.json`（跨日自动归零），与历史同为无锁读改写，朋友规模并发下可能小幅超配额；限额是防误触/防滥用，不防刻意刷。
